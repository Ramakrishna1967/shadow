HOW IT WORKS

Plan. Approve. Work. Report.

Every run follows the same four steps, so you always know what an agent is doing and why.

  1. STEP 01

    Plan

    State a goal in the agent's chat. It writes a short plan before it touches anything.

  2. STEP 02

    Approve

    You approve the plan. Each risky step asks again and shows the exact command, path or message.

  3. STEP 03

    Work

    It works in the folders and apps you granted, now or on a schedule.

  4. STEP 04

    Report

    A structured report lands in the chat: what was done, counts, and what is queued but not sent.

FAQ

Frequently asked questions.

01Does my data leave my PC?

There is no SHADOW cloud. The prompts, files and screenshots an agent uses go only to the model provider you choose, with your own key. Use Ollama to keep text on your machine.

02Can an agent act without asking?

Only inside what you granted, and risky actions ask first. You can choose "always allow" for one specific action of one agent. A deny rule always beats an allow rule.

03Can it see my passwords?

No. When a sign-in is needed, the agent pauses and you type it into the live window yourself.

04Which models does it use?

Anthropic, OpenAI, xAI, Google or Ollama, set per agent. You pay the provider directly. Screen control works with Claude models first; other models use every other tool.

05How many agents can I run?

Up to 20, groups included. Each has its own chat, model, permissions, skills and schedule.

06Is the installer signed?

Not yet. The early-access installer is unsigned, so Windows SmartScreen shows a warning. Signing comes later.

07Which platforms are supported?

Windows 11 for now.

08What if a run fails or hits a limit?

Every run has limits on turns, time and spend. When one is hit or a step fails, the run stops and the reason shows in the chat. Nothing is dropped silently.
